# Reverse-engineering findings and source

`research/imports/reverse-engineering-findings/16cf788207cc9c36f53876153abcce077c8f0356/` contains selected reverse-engineering findings at that source commit, clean working tree. Each snapshot includes its original `LICENSE.txt` (GNU GPL version 3 text), `CREDITS.md`, and a `manifest.json` listing every included file path with its SHA-256 hash; the current snapshot covers 110 files. The directory name is always the full source commit, so a later refresh adds a sibling snapshot instead of rewriting this one. Preserve these files and attribution when deriving implementations from imported source. This repository does not assign a replacement license to that material.

No game archive, binary, font atlas or captured session is included in any snapshot.
